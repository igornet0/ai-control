# Современная система аутентификации

## Обзор

Новая система аутентификации предоставляет современный, интуитивный и безопасный интерфейс для входа и регистрации пользователей в AI-CONTROL.

## Компоненты

### 1. ModernAuth.jsx
Главный компонент, объединяющий формы входа и регистрации.

**Особенности:**
- Анимированный фон с плавающими элементами
- Плавные переходы между вкладками
- Адаптивный дизайн
- Интеграция с существующей системой аутентификации

**Использование:**
```jsx
import ModernAuth from './components/auth/ModernAuth';

<ModernAuth login={loginFunction} />
```

### 2. ModernLoginForm.jsx
Современная форма входа с улучшенным UX.

**Функции:**
- Поля с анимированными метками
- Показ/скрытие пароля
- Валидация в реальном времени
- Состояния загрузки
- Обработка ошибок

**Особенности:**
- Автофокус на полях
- Анимации при взаимодействии
- Адаптивный дизайн
- Интеграция с контекстом аутентификации

### 3. ModernRegisterForm.jsx
Продвинутая форма регистрации с валидацией.

**Функции:**
- Валидация всех полей
- Индикатор силы пароля
- Проверка совпадения паролей
- Согласие с условиями
- Обработка ошибок сервера

**Валидация:**
- Имя пользователя: минимум 2 символа
- Email: корректный формат
- Логин: 3+ символа, только буквы, цифры и _
- Пароль: 6+ символов, заглавные/строчные буквы, цифры
- Подтверждение: совпадение с паролем

## Анимации

### Фоновые анимации
- **float**: Плавающие градиентные орбы (20s цикл)
- **floatShape**: Движение декоративных элементов (15s цикл)
- **pulseGlow**: Пульсация свечения логотипа (3s цикл)

### Интерактивные анимации
- **fadeInUp**: Появление элементов снизу вверх
- **slideInDown**: Появление сообщений сверху
- **spin**: Вращение спиннера загрузки

### Переходы
- **transition-base**: 300ms для основных переходов
- **transition-fast**: 150ms для быстрых взаимодействий
- **transition-slow**: 500ms для плавных анимаций
