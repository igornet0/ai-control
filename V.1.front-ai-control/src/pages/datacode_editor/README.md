# DataCode Web Editor - React Component

React компонент для отображения веб-редактора DataCode в приложении.

## 📋 Описание

Этот компонент (`DataCodeEditorPage.jsx`) загружает статический HTML редактор из `public/datacode-editor/` через iframe и передает ему конфигурацию API.

Статические файлы редактора находятся в: `public/datacode-editor/`

## 🎨 Особенности

- **Подсветка синтаксиса** - Полная поддержка синтаксиса DataCode с неоновыми цветами
- **Автодополнение (IntelliSense)** - Умные подсказки для ключевых слов, функций и переменных
- **Множественные вкладки** - Работа с несколькими файлами одновременно
- **Поиск и замена** - Быстрый поиск по коду (Ctrl+F)
- **История изменений** - Undo/Redo для отмены действий
- **Консоль вывода** - Панель для вывода результатов выполнения
- **Современный дизайн** - Темная тема в стиле Cyberpunk с неоновыми акцентами
- **Адаптивный интерфейс** - Работает на разных размерах экрана
- **Интеграция с API** - Автоматическая передача конфигурации API и токена авторизации

## ⌨️ Горячие клавиши

- **Ctrl+F** (Cmd+F на Mac) - Открыть панель поиска
- **Ctrl+Z** (Cmd+Z) - Отменить действие
- **Ctrl+Y** или **Ctrl+Shift+Z** - Повторить действие
- **Tab** - Вставить отступ (4 пробела)
- **Shift+Tab** - Убрать отступ
- **Enter** или **Tab** (в автодополнении) - Принять предложение
- **↑/↓** (в автодополнении) - Навигация по предложениям
- **Escape** - Закрыть автодополнение

## 🔧 Настройка

### Изменение цветовой схемы

Отредактируйте переменные CSS в `styles.css`:

```css
:root {
    --neon-purple: #B026FF;
    --neon-cyan: #00D9FF;
    --bg-primary: #0D0F14;
    /* ... другие цвета ... */
}
```

### Добавление новых функций в автодополнение

Отредактируйте массив `builtinFunctions` в `syntax-highlighter.js`:

```javascript
this.builtinFunctions = [
    // ... существующие функции ...
    'your_new_function'
];
```

## 🐛 Известные ограничения

- Поиск и замена работает базово (можно улучшить)
- Нет интеграции с реальным интерпретатором DataCode (только редактор)
- Мини-карта кода не реализована полностью
- Нет сохранения файлов на диск (работает только в браузере)
