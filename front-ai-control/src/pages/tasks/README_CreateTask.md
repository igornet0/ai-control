# Страница создания задач

## Описание

Современная страница для создания задач с богатым функционалом и красивым дизайном в стиле всего сайта.

## Функциональность

### ✨ Основные возможности

- **Структурированная форма** - логически разделенные секции для удобного заполнения
- **Шаблоны задач** - 5 готовых шаблонов для быстрого создания типовых задач
- **Валидация** - проверка обязательных полей и корректности данных
- **Теги** - система тегов для категоризации задач
- **Временные рамки** - настройка сроков выполнения и оценки времени
- **Проекты** - привязка задач к проектам
- **Адаптивный дизайн** - корректное отображение на всех устройствах

### 🎨 Дизайн

- **Современный UI** - градиенты, тени, анимации
- **Темная тема** - соответствует общему стилю сайта
- **Анимации** - плавные переходы и эффекты
- **Иконки** - эмодзи иконки для лучшего восприятия
- **Типографика** - четкая иерархия текста

### 📋 Шаблоны задач

1. **🐛 Исправление бага** - для исправления ошибок
2. **✨ Новая функция** - для разработки новых возможностей
3. **📋 Код-ревью** - для проверки кода
4. **🧪 Тестирование** - для задач тестирования
5. **📚 Документация** - для создания документации

## Структура компонента

### Основные секции

1. **Заголовок** - название страницы и навигация
2. **Шаблоны** - выбор готовых шаблонов (опционально)
3. **Основная информация** - название и описание задачи
4. **Настройки задачи** - статус, приоритет, тип, проект
5. **Временные рамки** - даты и оценка времени
6. **Теги** - система тегов для категоризации

### Состояния

- **Загрузка** - отображение спиннера при создании задачи
- **Валидация** - подсветка ошибок в полях
- **Успех** - перенаправление на страницу задач

## Использование

### Навигация

```jsx
// Переход на страницу создания задач
navigate('/tasks/create');
```

### Интеграция

Страница интегрирована в приложение через:

1. **Маршрут** - `/tasks/create` в `App.jsx`
2. **Кнопка** - в `HeaderTabs.jsx` на вкладке "Задачи"
3. **Сервис** - использует `taskService.createTask()`

### API

```javascript
// Создание задачи
const taskData = {
  title: 'Название задачи',
  description: 'Описание задачи',
  status: 'created',
  priority: 'medium',
  task_type: 'task',
  due_date: '2024-01-01',
  start_date: '2024-01-01',
  estimated_hours: 8,
  tags: ['tag1', 'tag2'],
  project_id: 1
};

await taskService.createTask(taskData);
```
