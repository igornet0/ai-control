# DataCode Web Documentation - React Component

React компонент для отображения веб-документации DataCode в приложении.

## 📋 Описание

Этот компонент (`DataCodeDocsPage.jsx`) загружает статическую HTML документацию из `public/datacode-docs/` через iframe.

Статические файлы документации находятся в: `public/datacode-docs/`

## 📁 Структура файлов

```
src/pages/datacode_docs/
├── DataCodeDocsPage.jsx      # React компонент страницы документации
├── DataCodeDocsPage.module.css  # Стили компонента
└── README.md                  # Этот файл

public/datacode-docs/          # Статические файлы документации
├── index.html                 # Главный HTML файл с документацией
├── styles.css                 # Стили и оформление
└── script.js                  # JavaScript для интерактивности
```

## 🎨 Разделы документации

1. **Обзор** - Введение в DataCode, основные возможности, типы данных
2. **Установка** - Инструкции по установке и настройке
3. **Быстрый старт** - Примеры для начала работы
4. **Синтаксис** - Подробное описание синтаксиса языка
5. **Функции** - Полный список встроенных функций с примерами
6. **Примеры** - Практические примеры использования
7. **Справочник** - CLI команды и справочная информация

## 🔧 Особенности

### Копирование кода

Каждый блок кода имеет кнопку "📋 Копировать" для быстрого копирования в буфер обмена.

### Фильтрация функций

В разделе "Функции" можно фильтровать функции по категориям:
- Все функции
- Системные
- Файлы
- Математика
- Массивы
- Строки
- Таблицы

### Адаптивность

Документация полностью адаптивна и отлично работает на:
- Десктопах
- Планшетах
- Мобильных устройствах

## 🎯 Кастомизация

### Изменение цветовой схемы

Отредактируйте переменные CSS в файле `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --background: #0f172a;
    --text: #f1f5f9;
    /* ... другие переменные */
}
```

### Добавление функций

Отредактируйте объект `functionsData` в файле `script.js`:

```javascript
const functionsData = {
    category_name: [
        {
            name: 'function_name',
            category: 'category_name',
            description: 'Описание функции',
            signature: 'function_signature',
            example: 'example code'
        }
    ]
};
```

## 📝 Обновление документации

При добавлении новых функций или изменении синтаксиса:

1. Обновите соответствующий раздел в `index.html`
2. Добавьте новые функции в `functionsData` в `script.js`
3. Обновите примеры кода при необходимости

## 🌐 Развертывание

Для развертывания на веб-сервере:

1. Загрузите все файлы в директорию веб-сервера
2. Убедитесь, что `index.html` доступен как индексный файл
3. Настройте правильные MIME-типы для `.css` и `.js` файлов

### GitHub Pages

Для развертывания на GitHub Pages:

1. Создайте репозиторий
2. Загрузите файлы в корневую директорию или в папку `docs`
3. Включите GitHub Pages в настройках репозитория
4. Выберите источник (branch или docs folder)
